## Speaker notes

This is not a criticism of datasets; abstraction is necessary for research. The danger is silently assuming that deployment supplies the same clean objects, labels, and distributions.

A model can solve the provided table while the production collection system systematically omits memory-only payloads, short-lived processes, or endpoint plaintext.
