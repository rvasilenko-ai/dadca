DADCA: Defense Against the Dark Cyber Arts

Understanding the Threat. Mastering the Defense.

An advanced lecture series on malware, machine learning, and AI-powered threat detection: how malware and malicious capabilities evolved, how the pipelines that detect them had to evolve with them, and what changes when the attacker is an agent and the detector is a model.

Roman Vasilenko · slides, speaker notes and sources · about the author · source repository

Intro

Lecture 1 · undergraduate and Master's · 90 minutes

From Malware Files to Adversarial Capabilities

How did malware and malicious capabilities evolve, and how did detection pipelines have to evolve with them?

Four periods from 2000 to 2026 across motive, attackers, operating system, internet and products; ATT&CK as a language for behavior; the detection pipeline, the options at each stage, and the host and network lineages rebuilt generation by generation; six misses to diagnose.

What changes when reasoning, tool use, and persistent trial-and-error become cheap?

Machine Learning for Malware Detection

Lecture 3 · Master's and PhD · 90 minutes

ML for Detection of Malicious Binary Files

What does each detector actually receive, and what did the extraction discard before it arrived?

Signatures, engineered features, similarity, raw-byte and code models, the file-centric benchmarks and what they hide, the same methods beyond files, and the LLM as analyst.

Friends' lectures

Saastha Vasan · guest lecture, UC Santa Barbara · 18 November 2026

Automating security work: from hand-written rules to LLM agents

Where did each generation of automation stall, and what does it take to make an LLM agent good at security work?

How security work has been automated, from hand-written rules and programs to machine learning and then LLM agents, and where each approach stalled; how LLM agents work, why making them better at security is still hard, and the two ways to improve them: the harness of tools and prompts around the model, and training the model itself. By Saastha Vasan, AI security researcher, for CMPSC 279 at UC Santa Barbara.
