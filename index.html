Malware and AI

A three-lecture series on how malware and malicious capabilities evolved, how the pipelines that detect them had to evolve with them, and what changes when the attacker is an agent and the detector is a model.

Roman Vasilenko · slides, speaker notes and sources · source repository

Lecture 1 · undergraduate and Master's · 90 minutes

From Malware Files to Adversarial Capabilities

How did malware and malicious capabilities evolve, and how did detection pipelines have to evolve with them?

Four periods from 2000 to 2026 across motive, attackers, operating system, internet and products; ATT&CK as a language for behavior; the detection pipeline, the options at each stage, and the host and network lineages rebuilt generation by generation; six misses to diagnose.

Lecture 2 · Master's and PhD · 90 minutes

When the Attacker Is an Agent

What changes when reasoning, tool use, and persistent trial-and-error become cheap?

Agents as operators and as targets: tools, feedback, persistence and delegated authority in an adversarial environment, and what the defender's telemetry has to become.

Lecture 3 · Master's and PhD · 90 minutes

Machine Learning for Malware Detection

What does each detector actually receive, and what did the extraction discard before it arrived?

Signatures, engineered features, similarity, raw-byte and code models, the file-centric benchmarks and what they hide, the same methods beyond files, and the LLM as analyst.
