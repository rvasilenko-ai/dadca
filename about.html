Research and patents

  • SCRUTINIZER: Detecting Code Reuse in Malware via Decompilation and Machine Learning

    DIMVA 2021, with colleagues at Northeastern University. Code reuse between malware samples found at the function level, from decompiled code, with unsupervised learning to discard the functions that carry no signal; the system attributed previously unknown samples to known APT campaigns.

  • DEEPCAPA: Identifying Malicious Capabilities in Windows Malware

    ACSAC 2024, with colleagues at UC Santa Barbara. A post-detection tool that reads the API call sequences of sandboxed malware from memory snapshots and maps them to MITRE ATT&CK techniques, so that an analyst learns what a sample can do, not only that it is malicious.

About this series

DADCA: Defense Against the Dark Cyber Arts is three related 90-minute lectures. Lecture 1, for undergraduate and Master's students, follows the malicious capability as it moved out of the executable file over twenty-five years, and the detection pipelines that had to move after it. Lecture 2, for Master's and PhD students, asks what changes when the attacker is an agent. Lecture 3, for the same audience, opens the detectors themselves: what each one actually receives, and what the extraction discarded before it arrived.

AI changes where human expertise is valuable; it does not eliminate the need for expertise.

The lectures show the gap between an academic prototype and an operational security system. Many operational problems occur before or after model inference: collection, extraction, representation, prioritization, tool integration, evidence preservation, authorization and response. Those gaps are where the research and engineering work is.

Everything is built in the open. Each slide is a markdown file with its speaker notes, its planned minutes and the sources behind every number; the decks are generated from those files, and dates and figures were checked against primary sources before publication. Offensive mechanics are kept conceptual throughout: the teaching objective is observability and system design.
