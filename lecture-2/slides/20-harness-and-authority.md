# Slide 20 — Harness and authority

**Timing:** 49–52 minutes  
**Module:** Why the agent succeeded

## On-slide content

```text
model capability
    + tool interfaces
    + shell/network access
    + credentials
    + persistent or recoverable state
    + environmental feedback
    + delegated authority
    = real-world consequences
```

## Speaker notes

The model is one component in a larger execution system. Ask not only “What can the model reason about?” but also:

- What actions can it request?
- Which actions execute without independent authorization?
- What identity do those actions inherit?
- What observations return to the model?
- Where is state retained?

This framing applies equally to offensive agents, coding agents, and defensive response agents.

## Transition

“The harness defines what is possible; the objective and feedback influence which possibilities are pursued.”
