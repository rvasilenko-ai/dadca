# Slide 2 — Standalone foundation

**Timing:** 1–5 minutes  
**Module:** Foundation

## On-slide content

### Malware is more than a file

`artifact · capability · control · objective · observability`

### ATT&CK describes behavior

`tactic -> technique -> procedure`

### Detection is a pipeline

```text
activity -> sensing -> extraction -> representation
         -> detection -> investigation -> decision -> response
```

## Speaker notes

Define each term in one sentence. A legitimate artifact can implement adversarial behavior under unauthorized control. ATT&CK helps describe what occurred without requiring a malware-family label. Detection can fail before or after classification.

## Transition

“The second foundation is scale: not every security problem can afford the same kind of reasoning.”
