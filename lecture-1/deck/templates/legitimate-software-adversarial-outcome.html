Same tool, different procedures; same technique, different tools. And when the artifact itself is legitimate and unchanged, where does “malicious” reside?

Remote-management tool abused T1219 Remote Access Tools · an ATT&CK tool, not malware

What it is
Legitimate remote-access software, installed as designed; the same binary and hash as every other install.
What differs from legitimate use
Who operates the session, and whose objective it serves.
Where “malicious” sits
Control and objective. The software works exactly as designed.
What a file classifier sees
A clean, signed, known program.

Vulnerable signed driver T1068 Exploitation for Privilege Escalation

What it is
A legitimate kernel driver with a valid signature and an exploitable flaw; the same binary and hash the vendor shipped.
What differs from legitimate use
Who loads it, and that its flaw is used beyond the driver's intended design.
Where “malicious” sits
Control and objective, and also capability: what it can be made to do.
What a file classifier sees
A clean, signed, known driver.

Neither differs as an artifact. The tool differs only in who controls it and whose objective it serves; the driver also in what it can do.
