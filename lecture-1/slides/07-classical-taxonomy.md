# Slide 7 — The classical taxonomy

**Timing:** 8–10 minutes  
**Module:** From malicious programs to adversarial capabilities

## On-slide content

| Term | Defining property |
| --- | --- |
| Virus | Attaches to a host and replicates |
| Worm | Self-propagates between systems |
| Trojan | Appears legitimate but performs hidden actions |
| Backdoor | Provides unauthorized access |
| Spyware | Collects information |
| Rootkit | Conceals or preserves privileged access |

## Speaker notes

The categories describe different dimensions. “Trojan” concerns presentation, “worm” propagation, “backdoor” capability, and “rootkit” concealment. A single specimen can occupy several categories simultaneously.

## Interaction

Ask whether ransomware belongs in the table as an artifact type, propagation mechanism, capability, or objective.

## Transition

“These categories became operational because files were convenient security objects.”
