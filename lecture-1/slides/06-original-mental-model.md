# Slide 6 — The original mental model

**Timing:** 7–8 minutes  
**Module:** From malicious programs to adversarial capabilities

## On-slide content

```text
malicious executable
    -> user or system executes it
    -> malicious behavior occurs
```

The suspicious object is persistent, transferable, and available for analysis.

> Working definition for this lecture: malware is the malicious capability. The file is one carrier of it, and this model assumes it is the only one.

## Speaker notes

Present this as a useful simplification, not an ignorant historical mistake. When a stable file carries the capability, defenders can intercept it before execution, retain it, hash it, label it, and share it.

State the working definition now, because the rest of Part 1 uses it: malware is the capability, and the file is a carrier. The model on the slide assumes the carrier is always a file, which was nearly true for fifteen years, and the four periods show the capability leaving it.

## Transition

“The familiar malware taxonomy grew around this object-centric model.”
